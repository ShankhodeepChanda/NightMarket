Project: Night Market

Night Market is a Flutter application for Android-first development with
future iOS support.

Core systems:
1. Marketplace
2. College Community
3. Student Skills Marketplace

Technology:
Flutter
Dart
Firebase
Git

Rules:
- Never attempt to build the entire application in one operation.
- Work incrementally.
- Inspect existing code before modifying it.
- Preserve existing functionality.
- Do not introduce unnecessary dependencies.
- Follow the existing architecture.
- Run flutter analyze after meaningful changes.
- Run relevant tests after meaningful changes.
- Do not claim a feature is complete without verifying it.
- Update documentation after architectural changes.
- Keep Android-specific code isolated where possible.
- Maintain future iOS compatibility.
- Never expose secrets or API keys in source code.
- Follow secure Firebase practices.
- Prefer maintainable and readable code over clever code.
- Explain important architectural decisions.
- Ask for clarification when a requirement is genuinely ambiguous.
